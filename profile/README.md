### 🚀 Getting started

**Relational lab**

```bash
git clone https://github.com/mavasbel-itam/relational-dbs-labs-setup.git
cd relational-dbs-labs-setup
uv sync
uv run jupyter lab
```

In JupyterLab, run `postgresql/postgresql_infra.ipynb` and then `postgresql/postgresql_dataload.ipynb`. The server listens on port `5423` with all eight databases loaded. The non-relational lab follows the same notebook-driven approach; see its [README](https://github.com/mavasbel-itam/non-relational-dbs-labs-setup#readme).

**Stream consumers**

```bash
git clone https://github.com/mavasbel-itam/stream-consumers.git
cd stream-consumers
uv sync
uv run stream-consumers consume wikimedia --max-events 5
```

The `wikimedia` source needs no API key and prints five events as JSON lines. The [README](https://github.com/mavasbel-itam/stream-consumers#readme) covers API keys, every destination, and the 73 sources.
